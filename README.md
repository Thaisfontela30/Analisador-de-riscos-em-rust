# 🛡️ Cyber Scanner - Analisador de Riscos em Rust

Um analisador de riscos de cibersegurança desenvolvido em **Rust**, focado em performance e segurança para identificar e avaliar vulnerabilidades potenciais.

## 📋 Sobre o Projeto

O **Cyber Scanner** é uma ferramenta robusta para análise de riscos em ambientes digitais, escrita em Rust. Aproveitando a segurança de memória e performance nativa de Rust, oferece uma solução confiável para profissionais de cibersegurança.

## ✨ Características

- 🚀 **Alta Performance** - Desenvolvido em Rust para máxima eficiência
- 🔒 **Segurança em Foco** - Sem vulnerabilidades de memory safety
- 🎯 **Análise de Riscos** - Identifica e classifica potenciais ameaças
- 📊 **Relatórios Detalhados** - Saídas estruturadas e fáceis de interpretar

## 🛠️ Pré-requisitos

- **Rust 1.70+** - [Instale Rust aqui](https://www.rust-lang.org/tools/install)
- **Cargo** - Incluído na instalação do Rust

## 📦 Instalação

### Clone o repositório

```bash
git clone https://github.com/Thaisfontela30/Analisador-de-riscos-em-rust.git
cd Analisador-de-riscos-em-rust
```

### Compile o projeto

```bash
cargo build --release
```

## 🚀 Como Usar

### Executar o Scanner

```bash
cargo run --release
```

### Executar Testes

```bash
cargo test
```

### Build para Produção

```bash
cargo build --release
```

O executável compilado estará em `target/release/cyber_scanner`.
